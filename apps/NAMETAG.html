Grade 1 admission tag sheet

One row per student. Leave a number blank if that student doesn't need that category.

# Name සහෝදර ආසන්න ආදිශිෂ්‍ය කාර්ය මණ්ඩල

Each filled-in category prints as: Year / Word / Number — e.g. "2026 / සහෝදර / 39". A student can have one, two or all three.

Cover pages: a frame around the page, a title, pictures, and a name at the bottom. Every page has its own title, pictures and bottom name, so you can make one page per child. Each page prints on its own A4 sheet.

Page frame

Paper

Printing uses no page margin so the frame sits where you set it. Keep "From page edge" at 5 mm or more, because most printers can't print right to the paper edge. The preview shows the page you are editing; Print and the PDF ZIP include every page.

Auto reset

minutes with no activity

Puts every tab back the way the page first opens — names, pictures, sizes and all choices — so the next person starts fresh. It only happens if something was changed, and a warning with a "Keep my work" button shows for the last 60 seconds. Your saved subject list is not touched.
